# Smart Wardrobe - Система анализа гардероба с использованием YOLO

## Описание
Проект для автоматического распознавания предметов одежды на изображениях с применением моделей YOLO (You Only Look Once). Система позволяет анализировать содержимое гардероба, классифицировать предметы одежды и сохранять результаты для дальнейшей обработки.

## Функциональность
- **Детекция объектов** - автоматическое обнаружение предметов одежды на изображениях
- **Классификация** - определение категорий одежды (футболки, брюки, обувь и др.)
- **Аннотирование** - разметка bounding boxes с указанием уверенности модели
- **Экспорт результатов** - сохранение данных в структурированном JSON формате
- **Подготовка данных** - инструменты для создания и проверки датасетов в YOLO формате

## Технический стек
- **Python 3.11.14**
- **Ultralytics YOLO** (v8/v9) - фреймворк для детекции объектов
- **Pillow** - обработка изображений
- **PyTorch** - машинное обучение
- **Conda/Pip** - управление зависимостями

## Установка и настройка

### Способ 1: Использование Conda (рекомендуется)
```bash
# Создание виртуального окружения из конфигурационного файла
conda env create -f environment.yml

# Активация окружения
conda activate smart_wardrobe
Способ 2: Использование pip
bash
# Установка зависимостей
pip install -r requirements.txt

Использование
1. Обработка изображений гардероба
bash
python src/run_model.py
Скрипт последовательно обрабатывает все изображения в директории test_images/, применяет модель YOLO и сохраняет результаты детекции в файл results.json.

2. Тестирование с визуализацией результатов
bash
python src/test_model.py
Запускает модель на тестовых изображениях, добавляет визуальные bounding boxes с подписями классов и сохраняет аннотированные изображения для анализа качества работы.

3. Подготовка пользовательского датасета
bash
# Конвертация существующего датасета в YOLO формат
python src/preparing_dataset/convert_to_yolo.py --input_dir /путь/к/датасету --output_dir dataset_yolo

# Проверка корректности подготовленного датасета
python src/preparing_dataset/verify_dataset.py --dataset_path dataset_yolo

text
